| **Project Name** | TalentRank — Explainable Machine Learning for Employee Promotion Prediction and Ranking |
| **Domain** | Human Resources / Talent Management / Machine Learning / Explainable AI |
| **Problem Statement** | Companies need to review employee information when making promotion decisions. However, it can be difficult to compare many employees consistently and understand which recorded factors influence a model's promotion prediction. This project aims to develop and compare machine learning models that predict historical employee promotion outcomes, rank employees according to their predicted outcomes, and explain which features influence the predictions. The system is intended to support HR Talent Management Specialists and management, not to make final promotion decisions. |
| **Evidence of the Problem** | Evidence 1: A public HR Analytics promotion dataset contains 54,808 employee records and 13 columns, including employee-related features and a binary promotion outcome. This provides data for studying historical promotion patterns and testing machine learning models. The target is historical promotion, not a verified measure of leadership potential or suitability for a specific senior role.<br>Source / citation: Kaggle, *HR Analytics: Employee Promotion Data* — https://www.kaggle.com/datasets/muhammadimran112233/employees-evaluation-for-promotion<br><br>Evidence 2: Research on the same 54,808-record dataset has compared machine learning methods for employee promotion prediction and investigated which recorded features are associated with predictions. This shows the dataset has been used for this task, while leaving room to test a clearly defined model comparison and explanation workflow.<br>Source / citation: *Analysis and Prediction of Employee Promotions Using Machine Learning*, 2022 IEEE International Conference on Data Science and Information Technology — https://ieeexplore.ieee.org/document/9943959/<br><br>**Evidence note:** these sources support the use of historical HR data for promotion prediction research. They do not prove the dataset can identify future Department Managers or CEOs, or that the features cause promotion decisions. |

| **Engineering Gap / Limitation** | What practical or technical limitation remains unresolved?<br>Gap / Limitation: the selected public dataset supports prediction of historical promotion outcomes, but it does not directly measure leadership potential or state whether an employee was promoted to Department Manager, Director, or CEO. The practical engineering task is to compare suitable ML models, investigate ranking employees by predicted promotion probability, and explain the features that influence predictions — evaluating predictive performance, ranking quality where suitable relevance labels exist, and explanation usefulness. It will not claim to identify the true causes of promotion or prove the highest-ranked employee should be promoted. This is a project-specific engineering question to evaluate, not a claim that no similar system exists. |
| **Initial Project Objectives (2–3)** | O1: To investigate employee features associated with historical promotion outcomes in a public HR dataset.<br>O2: To develop and compare machine learning models for employee promotion prediction and ranking.<br>O3 (if applicable): To evaluate model performance and explain the features that influence the predictions. |
| **Target Users** | Primary: HR Talent Management Specialists who review employee promotion patterns and support talent-management discussions. Secondary: Department Heads, Directors, General Managers, and other senior management who review HR analysis. Intended use: provide additional information for human review and discussion. Out of scope: automatically selecting employees for promotion or claiming the system can identify future CEOs or successful leaders. |

| **Similar to EduAdvisor** | Like EduAdvisor, this project uses data and machine learning to provide decision-support information and aims to make the output easier to understand. Both projects should be evaluated against clear criteria and should communicate limitations rather than presenting every model output as certain. |
| **Different from EduAdvisor** | EduAdvisor supports students with academic information, while this project analyses historical employee promotion outcomes. It compares machine learning models, explores employee rankings based on predicted promotion probabilities, and explains influential recorded features. Unlike a system designed for direct academic guidance, this project concerns a sensitive HR context, so it must clearly state that predictions are not proof of employee ability and must not replace human judgement. |
| **Responsible AI Risks (at least 2)** | Risk 1 — Historical bias and unfair ranking: historical promotion labels may reflect past organisational practices or unequal opportunities; a model may reproduce these patterns or produce different error rates across employee groups. Mitigation: check performance across relevant groups where data allows, document limitations, and do not use protected attributes to make individual recommendations.<br>Risk 2 — Overreliance on AI predictions: HR staff or managers may treat the highest predicted probability as a recommendation to promote. Mitigation: display predictions as estimates based on historical data, include limitations, require human review, never automate decisions.<br>Risk 3 (if any) — Misinterpreting feature importance: a feature that influences a prediction is not necessarily a cause of promotion. Mitigation: describe explanations as model behaviour, not causal evidence. Two further risks also apply: Risk 4 — Data privacy and misuse: use only the public dataset, never add private employee records. Risk 5 — Data and target limitations: the dataset does not specify promotion destination or validate leadership potential; role-specific leadership ranking is future work requiring suitable role-level data. |
