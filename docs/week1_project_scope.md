| **Project Name** | Leadership Competency Evidence Ranking Assistant |
| **Domain** | Human Resources Development / Leadership Competency Frameworks / Information Retrieval / Explainable AI |
| **Problem Statement** | Public leadership frameworks describe competencies and behaviours relevant to leadership roles, but a user may need to consult multiple frameworks and manually locate the descriptions that relate to a particular behavioural example. This project investigates whether an AI-assisted retrieval and ranking prototype can help users find relevant competency passages more efficiently while keeping the evidence and source visible. The tool supports competency exploration and development reflection only; it does not determine a person's leadership potential or make employment decisions. |
| **Evidence of the Problem** | Evidence 1: Public frameworks contain structured descriptions of leadership competencies and expected behaviours (e.g. University of Minnesota Leadership Competency Framework, Government of Canada Key Leadership Competency Profile), but these descriptions are scattered across separate documents with no unified way to search them by behavioural evidence.<br>Source / citation: https://hr.umn.edu/Professional-Development/Supervisory-and-Leadership-Development/Leadership-Competencies-and-Assessments/Leadership-Competency-Framework ; https://www.canada.ca/en/treasury-board-secretariat/services/professional-development/key-leadership-competency-profile.html<br><br>Evidence 2: Published research already studies leadership-potential assessment and succession planning, indicating that leadership assessment is an established topic rather than an unexplored problem — this is relevant context, but does not by itself establish that this proposed retrieval design is valid.<br>Source / citation: Groves (2025), "Assessing Leadership Potential for Succession Planning in the Digital Era of Work and Organizations," Academy of Management Proceedings. *(Exact bibliographic record to be verified through the university library before final submission.)*<br><br>**Evidence limitation:** these sources show that competency frameworks and leadership assessment exist; they do not prove every organisation experiences the same difficulty, nor that this proposed system improves decisions. User testing and a focused review are still needed. |

| **Engineering Gap / Limitation** | Ranking algorithms, leadership assessment approaches, and explainability methods are already individually studied (see Related Work). The engineering question for this project is whether a small, source-grounded prototype can rank relevant competency passages from multiple public frameworks, provide traceable evidence, and remain consistent enough for competency exploration. This gap is **to be investigated**, not a claim that no similar system exists. |
| **Initial Project Objectives (2–3)** | O1: To design an AI-assisted system that retrieves and ranks leadership competency passages from selected public frameworks using fictional behavioural evidence.<br>O2: To implement and compare a lexical retrieval baseline (e.g. BM25) with a semantic-similarity approach, where feasible.<br>O3 (if applicable): To evaluate ranking relevance, source traceability, response time, wording consistency, and scope-control behaviour. |
| **Target Users** | Learning and development practitioners exploring leadership competencies; HR practitioners preparing non-decisional leadership development resources; individuals who want to explore public leadership competency frameworks for personal development. |
| **Data Sources (at least 2)** | Source 1: University of Minnesota — Leadership Competency Framework — URL: https://hr.umn.edu/Professional-Development/Supervisory-and-Leadership-Development/Leadership-Competencies-and-Assessments/Leadership-Competency-Framework<br>Source 2: Government of Canada — Key Leadership Competency Profile — URL: https://www.canada.ca/en/treasury-board-secretariat/services/professional-development/key-leadership-competency-profile.html<br>Source 3 (if any): U.S. Office of Personnel Management — Executive Core Qualifications — URL: https://www.opm.gov/policy-data-oversight/senior-executive-service/executive-core-qualifications/<br><br>**Data limitation:** these are public frameworks, not employee-level datasets with validated promotion or leadership-success labels. They support document retrieval and relevance evaluation, not supervised prediction of actual leadership success. The three frameworks come from different institutional contexts and should not be assumed directly interchangeable without documenting the mapping. |
| **Similar to EduAdvisor** | Both use a defined set of public documents as a knowledge base; both need retrieval, source tracking, evaluation, and clear scope controls; both must show evidence so users can verify outputs rather than trusting an unexplained answer. |
| **Different from EduAdvisor** | This project ranks competency passages relevant to fictional behavioural evidence rather than answering free-text academic-advising questions. Evaluation focuses on ranking relevance, source traceability, response time, and wording consistency rather than conversational Q&A quality. It will not recommend an employment or promotion decision, which carries materially higher Responsible AI stakes than EduAdvisor's informational use case. |
| **Responsible AI Risks (at least 2)** | Risk 1: Misinterpretation / overreliance — a user may mistake a text-similarity rank for a validated measure of leadership potential. Mitigation: label scores as relevance scores, show source text, and state limitations.<br>Risk 2: Bias and inconsistent ranking — wording, cultural context, or framework choice may affect which competencies are retrieved. Mitigation: use multiple public frameworks carefully, test equivalent paraphrases, and report differences.<br>Risk 3 (if any): Privacy — real employee examples may include sensitive information. Mitigation: use fictional, non-identifying profiles only.<br>Risk 4 (if any): Unfair employment use — outputs could be misused to rank real employees or justify promotion decisions. Mitigation: exclude real-person comparisons and employment recommendations from the system scope entirely. |
